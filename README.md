## 🚀 Costs (V5) - Gestão Inteligente de Projetos e Custos

O Costs é uma aplicação web de gestão de orçamentos e controle financeiro de serviços para projetos. O projeto foi desenhado focando em escalabilidade, resiliência no gerenciamento de estados assíncronos, formulários orientados a schemas e estratégias robustas de testes automatizados (unitários, integração e E2E).

---

## 💡 Sobre o Projeto & Origem

Este projeto foi construído tomando como referência visual e inspiracional o projeto COSTS do curso de React do Matheus Battisti.

Contudo, toda a arquitetura de código, regras de negócio, lógica de estados assíncronos, formulários dinâmicos e a suíte completa de testes foram 100% projetadas e desenvolvidas por mim. A proposta desta versão (V5) é transformar uma interface simples de estudo em uma aplicação resiliente de nível de produção.

---

## Stack Tecnológica
* **Frontend:** React (Build tool: Vite)
* **Linguagem:** JavaScript (JS)
* **Gerenciamento de Estados Assíncronos:** TanStack Query (React Query)
* **Gerenciamento de Formulários:** React Hook Form
* **Validação de Dados:** Zod
* **Comunicação HTTP:** Fetch API
* **Backend Simulado:** JSON-Server (executado na render)
* **Testes Unitários/Integração:** Vitest
* **Testes E2E:** Playwright
